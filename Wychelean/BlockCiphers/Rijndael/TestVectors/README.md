# AES test vectors

Unmodified ECB `.rsp` files from [NIST CAVP](https://csrc.nist.gov/projects/cryptographic-algorithm-validation-program/block-ciphers), generated by CAVS 11.1 in 2011, line endings preserved. The other modes in each archive are omitted. The file format is described in [AESAVS](https://csrc.nist.gov/CSRC/media/Projects/Cryptographic-Algorithm-Validation-Program/documents/aes/AESAVS.pdf "sha256sum: 40294008c768fc6a9df0e530431b841b331c23b58f31b268dcff1e9a36db7411").

- `KAT_AES/`: [known-answer archive](https://csrc.nist.gov/CSRC/media/Projects/Cryptographic-Algorithm-Validation-Program/documents/aes/KAT_AES.zip "sha256sum: a203b16c9246b2ebae31dee5de21a606be80cf78ceabaca37150236fa098eb60")
- `aesmmt/`: [multi-block message archive](https://csrc.nist.gov/CSRC/media/Projects/Cryptographic-Algorithm-Validation-Program/documents/aes/aesmmt.zip "sha256sum: 12d1616f7a713e807714055973f04efc402f46a14e3d81869717c7ace4ecbaf0")
- `aesmct/`: [Monte Carlo archive](https://csrc.nist.gov/CSRC/media/Projects/Cryptographic-Algorithm-Validation-Program/documents/aes/aesmct.zip "sha256sum: 6a2a72c00b1daacb9a7d20ab92617d322fa1c5dee493968660990e3f4571426b")
