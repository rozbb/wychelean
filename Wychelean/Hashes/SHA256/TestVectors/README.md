# SHA256 fixtures

Unmodified `.rsp` files from [NIST CAVP](https://csrc.nist.gov/projects/cryptographic-algorithm-validation-program/secure-hashing), generated by CAVS 11.x in 2011, line endings preserved.

- `shabytetestvectors/`: [byte-oriented archive](https://csrc.nist.gov/CSRC/media/Projects/Cryptographic-Algorithm-Validation-Program/documents/shs/shabytetestvectors.zip)
  - SHA-256: `929ef80b7b3418aca026643f6f248815913b60e01741a44bba9e118067f4c9b8`
  - Vendored: `SHA256ShortMsg.rsp`, `SHA256LongMsg.rsp`, `SHA256Monte.rsp`
- `shabittestvectors/`: [bit-oriented archive](https://csrc.nist.gov/CSRC/media/Projects/Cryptographic-Algorithm-Validation-Program/documents/shs/shabittestvectors.zip)
  - SHA-256: `cd7b9f11680c6e0ccdbe13b28403f2017b5ff48789152162461e0a24fb4c5d45`
  - Vendored: `SHA256ShortMsg.rsp`, `SHA256Monte.rsp`; the multi-megabyte `SHA256LongMsg.rsp` is not vendored.

Lengths are in bits. Bit-oriented messages fill each byte from its most significant bit (FIPS 180-4 §3.1); the unused low bits of the last byte are zero. Monte Carlo follows [SHAVS §6.4](https://csrc.nist.gov/CSRC/media/Projects/Cryptographic-Algorithm-Validation-Program/documents/shs/SHAVS.pdf).
