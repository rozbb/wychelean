# SHA3 fixtures

Unmodified `.rsp` files from [NIST CAVP](https://csrc.nist.gov/projects/cryptographic-algorithm-validation-program/secure-hashing), generated by CAVS 19.0 in January 2016.

- `sha-3bytetestvectors/`: [byte-oriented archive](https://csrc.nist.gov/CSRC/media/Projects/Cryptographic-Algorithm-Validation-Program/documents/sha3/sha-3bytetestvectors.zip)
  - SHA-256: `cd07701af2e47f5cc889d642528b4bf11f8b6eb55797c7307a96828ed8d8fc8c`
- `sha-3bittestvectors/`: [bit-oriented archive](https://csrc.nist.gov/CSRC/media/Projects/Cryptographic-Algorithm-Validation-Program/documents/sha3/sha-3bittestvectors.zip)
  - SHA-256: `339454bb4b96e299fefcad403797523f1952462a28d2418c108aea30263643ae`

Each archive supplies short-message, long-message, and Monte Carlo vectors for SHA3-224, SHA3-256, SHA3-384, and SHA3-512. Lengths are in bits; Monte Carlo follows [SHA3VS §6.2.3](https://csrc.nist.gov/CSRC/media/Projects/Cryptographic-Algorithm-Validation-Program/documents/sha3/sha3vs.pdf).
