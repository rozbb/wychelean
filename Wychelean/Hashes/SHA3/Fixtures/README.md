# NIST SHA3 and SHAKE fixtures

Downloaded unchanged from the [NIST CAVP secure hashing page](https://csrc.nist.gov/projects/cryptographic-algorithm-validation-program/secure-hashing).
The response files were generated by CAVS 19.0 in January 2016. Length fields are in bits.
The test driver runs all 15,092 direct cases and all 1,200 Monte Carlo checkpoints.
Each checkpoint executes 1,000 iterations, using SHA3VS §6.2.3 or §6.3.3, not the SHA256 procedure.

Non-byte-aligned bit strings use low bits of the final byte; unused high bits must be zero.
The parser validates encoded lengths, output bounds, and sequential COUNT fields.
Empty messages use NIST's `Len = 0, Msg = 00` convention.

[SHA3VS](https://csrc.nist.gov/CSRC/media/Projects/Cryptographic-Algorithm-Validation-Program/documents/sha3/sha3vs.pdf)
defines the Monte Carlo recurrence. SHAKE uses the rightmost two output bytes as a big-endian
integer to choose the *next* output length; the checkpoint records the length just used.
